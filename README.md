# Data-Portfolio
1.This dashboard shows how bike products are performing from different angles like sales, profit, customer age, and location. You can see which products sell the most, how revenue changes over time, and how different age groups behave. It also includes a map to show discount patterns across regions. Everything is interactive, so users can filter by date and age to explore the data more easily.

Tableau Portfolio link 1 : https://public.tableau.com/app/profile/vincent.purnomo/viz/BikeProductsSales/Dashboard1?publish=yes

2.This dashboard shows airline reviews from different angles like overall rating, seat comfort, and service. You can see how ratings change over time, compare airlines, and check daily patterns. It also lets you filter by airline, traveller type, and category to explore the data easily.
